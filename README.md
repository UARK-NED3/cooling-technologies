# Cooling Technologies: Principles, Systems, and Applications

An open, self-paced introduction to cooling technologies for engineers and technically curious learners.

This repository is the course home. It is structured for direct reading on GitHub and is ready to be served with GitHub Pages from the `main` branch's `/docs` folder.

## Start here

Open the [course home](docs/index.md), then follow the six modules in sequence. Each module includes learning objectives, a conceptual lesson, a worked engineering check, common failure modes, and a transfer task.

## Scope and evidence status

The course explains first-principles, screening-level reasoning about cooling systems. It is **not** a substitute for equipment selection, code compliance, safety review, or professional design. Numerical examples are illustrative; property values and equipment performance must be verified for the applicable fluid, geometry, operating condition, and governing standard before design use.
