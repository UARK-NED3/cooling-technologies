# Changelog

All notable changes to the course are documented here. Versions describe the released teaching material, not a professional credential or a validated engineering design package.

## 0.6.2 — 2026-10-17

- Corrected the multi-line control-volume energy balance so GitHub Markdown does not interpret its continuation terms as list items.

## 0.6.1 — 2026-10-17

- Reorganized the Module 2 mechanism relations into an aligned display equation so the expressions remain legible in the published responsive layout.

## 0.6.0 — 2026-10-17

- Added textbook-style TeX equation rendering across the GitHub Pages course, including the engineering screening tools.
- Added a course-wide nomenclature with SI units, subscript rules, temperature-location guidance, and an explicit energy-balance sign convention.
- Converted governing relations and worked calculations in the modules, study manual, cases, assessment, and facilitator material to shared notation.

## 0.5.2 — 2026-10-17

- Improved the interactive tool-card layout so each calculation result is displayed on its own readable row.

## 0.5.1 — 2026-10-17

- Corrected the interactive screening-tools page so its engineering guidance and links render as HTML on GitHub Pages.
- Added a browser-page regression test and made the documentation workflow run the full local test suite.

## 0.5.0 — 2026-10-17

- Added an engineering-problem entry page, local transparent screening calculators, and application-specific routes from first question to next evidence step.
- Added reusable problem-definition, evidence-register, validation-plan, and screening-review templates.
- Added a validation ladder and a public cold-plate CFD case study that distinguishes simulated evidence from design qualification.

## 0.4.0 — 2026-10-17

- Added a self-paced study manual that organizes the six modules into an independent-study pathway with explicit outputs, worked reasoning checks, and a screening-memo completion standard.
- Linked the manual from course navigation and distinguished it from the separate instructor-led professional workshop.

## 0.3.0 — 2026-10-17

- Added NED3 applied examples that distinguish public simulated, measured/reconstructed, synthetic, and local-inventory evidence.
- Added a public cold-plate CFD assessment case and facilitator guidance on model scope, pressure-drop units, and surrogate applicability.
- Added traceable links to NED3 datasets, experimental toolkits, and data-center teaching resources without rehosting raw laboratory files.

## 0.2.0 — 2026-10-17

- Added a four-hour electronics thermal-design workshop pathway, assessment, illustrative cases, and facilitator guide.
- Added an evidence map that labels teaching models, illustrative values, assumptions, and design-use evidence needs.
- Corrected the Module 1 energy-balance boundary and clarified the radiation, phase-change, and liquid-property limitations.
- Added accessibility, maintenance, reuse, citation, and automated internal-link-check guidance.

## 0.1.0 — 2026-10-17

- Published the initial six-module self-paced course.
