# Maintenance and governance

## Scope

This repository is open educational material maintained by the NED³ Laboratory. It is not an official University of Arkansas course, standards document, product specification, or design authority. The public repository must not contain student records, participant submissions, unpublished research results, sponsor-restricted material, credentials, or proprietary device data.

## Change categories

| Change type | Minimum review before release |
| --- | --- |
| Typographical, navigation, or accessibility improvement | Maintainer review and documentation check |
| New illustrative exercise or workshop activity | Technical review of arithmetic, units, assumptions, and intended learning outcome |
| New engineering relation, property value, correlation, standards claim, or equipment-performance statement | Subject-matter review; primary or authoritative source; stated applicability and evidence status |
| Credentialing, host policy, safety, or regulatory statement | Hosting organization and qualified subject-matter review for the relevant jurisdiction and delivery context |

## Source and rights record

For each contribution, record the author, date, source location and version, reuse rights, evidence category, intended page, and technical reviewer when applicable. Use repository-authored figures or assets when possible. Before adding third-party content, confirm that public redistribution, attribution, and accessibility adaptation are permitted.

## Release practice

Use a versioned release for material changes. Update [CHANGELOG.md](../CHANGELOG.md), [CITATION.cff](../CITATION.cff), affected sources, and the evidence map together. Run the documentation check before merging. For high-consequence teaching content, retain the calculation sheet or technical-review record outside the public repository when it contains protected information.

## Review cadence and feedback

Review links, sources, standards references, safety statements, and workshop examples at least annually and before a public instructor-led offering. Treat a credible issue report about a technical error, access barrier, or broken link as a release-blocking item until it is assessed. Contributors should follow [CONTRIBUTING.md](../CONTRIBUTING.md) and make the smallest traceable change that resolves the issue.
