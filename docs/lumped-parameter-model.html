Lumped-parameter thermal simulator

This local tool evaluates the one-node model in Module 7. Your inputs stay in your browser; the page does not transmit or save them. The temperature trace is a derived, screening-level result of the stated constant resistance, constant capacitance, and constant sink-temperature assumptions—not a validated hardware prediction.

Model inputs

All inputs use SI units. A step load replaces the baseline load at the step time.

Temperature response

$$C_{\mathrm{th}}\frac{\mathrm{d}T}{\mathrm{d}t}=\dot{Q}_{\mathrm{load}}-\frac{T-T_{\mathrm{sink}}}{R_{\mathrm{th}}},\qquad \tau=R_{\mathrm{th}}C_{\mathrm{th}}$$

━━ node temperature   ┄┄ sink temperature   ┄┄ load step

Interpretation and limits

  • The model solves each constant-load interval exactly; the plot sample interval affects resolution, not the mathematical solution within the stated one-node model.
  • Use a separate node or a spatial model if an interface, heat spreader, fluid, or protected component has a materially different temperature.
  • Do not treat the equivalent resistance as constant if airflow, flow rate, phase, contact condition, or sink temperature changes materially over the event.
  • Record the input source, system boundary, temperature location, time basis, and evidence status in the assumption and evidence register.
