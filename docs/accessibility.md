# Accessibility and inclusive delivery

## Current approach

The course is authored as structured Markdown so it can be read on GitHub, GitHub Pages, or in a text-oriented format. Headings are ordered, tables use column labels, equations are written in both standard symbols and surrounding explanatory prose, and diagrams use text characters rather than information-bearing images. This is an implementation approach, not a claim of formal accessibility conformance.

## Instructor checklist

- Provide the materials before an instructor-led session in a usable digital format and allow adequate time for calculation activities.
- Describe every diagram, graph, or demonstration in words, including the physical direction of heat flow and the location of the measured temperature.
- Do not convey model status only through color, position, or animation. Label inputs as measured, reported, simulated, assumed, derived, or unknown in text.
- Give equations with variable definitions, units, sign conventions, and a plain-language statement of their model boundary.
- Ensure any added figure has concise alternative text and a caption that identifies whether it is measured, simulated, reconstructed, conceptual, or illustrative.
- Check contrast, keyboard use, zoom behavior, captions or transcripts for media, and the readability of exported worksheets in the actual host platform.

## Feedback

Report an access barrier through the repository's issue tracker with the page, delivery platform, assistive technology or interaction context if you wish to share it, and the outcome that was blocked. Do not include confidential learner or employment information in a public issue.
